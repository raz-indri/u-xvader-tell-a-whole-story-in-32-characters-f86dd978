One Wi-Fi network name (26 characters) that lands a joke and implies a whole
story: a neighbour hacker brags about breaking into Dave's smart fridge.
The name won a 28-pair duel test against 7 other drafts, 7-0 — see DUEL.md.

## Run it

```sh
python3 main.py
```

Writes the single entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`)
and prints exactly that one line to stdout.
